# Vault7 implementation plan

**Goal** Build an Android app for incremental, password-encrypted photo and video archives.

**Architecture** A native activity starts a foreground service. MediaStore supplies the ordered original media, a streaming 7z writer calculates the exact stored size, and SQLite records a media version only after its archive is published.

1. Add the Android module, app manifest, and GitHub Actions workflow.
2. Implement streaming 7z storage with AES-256 for data and headers. Test exact sizing, encrypted names, extraction with upstream 7-Zip, and original bytes.
3. Implement MediaStore selection, calendar and size grouping, and transactional backup records. Test cutoff behavior and date boundaries.
4. Add the Android screens for permissions, output directory, saved password, the four backup modes, and progress.
5. Run the verification suite and APK build in GitHub Actions and attach the checked APK to the release.
