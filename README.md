# Vault7

Vault7 将 Android 相册里的图片和视频原件保存为 AES-256 加密的 7z。支持 Android 11 及以上版本。APK 可在 [GitHub Releases](https://github.com/Johnn-Lee/Vault7/releases) 下载。

## 使用

1. 允许访问完整相册和原件位置信息。原件权限保留照片中已有的拍摄位置元数据。
2. 选择手机上的输出目录并设置全局密码。输出目录需要支持写入、随机访问和重命名。
3. 选择指定日期、单包大小上限、每隔 N 天批量打包或按大小批量分包。
4. 开始备份。批量方式一次启动就处理整个范围。每个 .7z 都可以独立解压。包名使用包内最早与最晚日期，例如 `20260101_20260201.7z`。同名时追加 `_02`、`_03`。

使用手机当前时区和拍摄日期。缺失拍摄日期时用入库日期。大小按 MiB 输入，上限包含最终归档头和加密开销。单文件仍超上限时，批量模式列出遗漏并继续。

Vault7 使用 7z 存储模式，原始媒体不转码。文件名和内容都加密。每次按所选范围和分包规则处理相册媒体。全局密码保存在手机上，卸载 App 会清除该设置。更改全局密码只影响新包。

## 构建

GitHub Actions 运行 Android lint、单元测试、7-Zip 独立解压验证和 APK 签名校验。当前构建作为预发行版发布。未配置正式签名密钥时，构建使用 GitHub Runner 的临时调试密钥，后续 APK 不能覆盖安装到该版本上。正式签名可以通过仓库 Actions secrets 配置。

归档写入参考 [7-Zip 格式规范](https://github.com/ip7z/7zip/blob/main/DOC/7zFormat.txt)。
